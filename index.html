Change detection

Single-probe visual working memory task. A memory array of coloured squares appears briefly, and after a blank retention interval one square returns at a previously occupied location. The participant judges whether its colour matches.

Lifespan Cognitive Development
Participant
Design

Choose up to three set sizes. Each one runs in its own blocks.

Timing

Canonical values run 100 to 500 ms exposure and a 900 ms retention interval.

Display

With the grid on, squares occupy the eight outer cells of a visible 3 × 3 grid, never the centre cell, which holds the fixation cross. Minimum separation then has no effect, since the cells fix the spacing.

Response
Data saving

Every session uploads to the study's Google Drive folder, the same folder the Shopping Game writes to. Uploads retry on their own, and the CSVs can always be downloaded from the results screen as a backup.
